# PondGuard M6.7 — Pre-Fabrication Electrical Review & BOM Freeze Candidate

## Purpose

M6.7 converts the M6.6 reference schematic into a procurement-oriented electrical review. It freezes the parts that can be frozen from authoritative vendor data and explicitly flags items that still require a purchased-module confirmation.

## Review result

**Status: PRE-FABRICATION REVIEW / BOM FREEZE CANDIDATE**

The design is not yet a fabrication release because the exact 2S BMS implementation, solar-panel MPN, SIM800L breakout, SSR/relay variant, connector family, and PCB footprints must still be confirmed against the parts physically procured.

## Key changes from M6.6

1. Replace the M6.6 placeholder 5 V buck with **TI LMR51430XFDDCR**. The device is active, accepts 4.5–36 V, and supports 3 A continuous output. [Web-verified]
2. Use the same regulator family for the **3.3 V** sensor/MCU rail and dedicated **4.0 V SIM800 rail**, avoiding AMS1117 and avoiding MP2307 for a new design.
3. Retain **CN3722** as the solar charger controller. Its input range is 7.5–28 V and it supports multi-cell Li-ion charging with external voltage/current programming. [Web-verified]
4. Retain **ADS1115**; use **ADS1115IDGSR** as the PCB device candidate. It is active, 16-bit, 4-channel and supports 2.0–5.5 V supply. [Web-verified]
5. Keep GPIO18/19 for MicroSD only if native USB-Serial-JTAG is intentionally disabled; Espressif documents GPIO18/19 as USB pins and GPIO2/8/9 as strapping pins. [Web-verified]
6. Keep SIM800L on a dedicated 4.0 V rail. SIMCom specifies 3.4–4.4 V, recommends 4.0 V, and calls for up to 2 A burst current with local low-ESR bypassing. [Web-verified]

## Power-rail acceptance targets

- 2S protected Li-ion pack: 6.0–8.4 V operating window assumed for the system review.
- CN3722 PV input: choose a panel with **Vmp >= 7.5 V**; exact panel MPN remains procurement-dependent.
- 5 V rail: LMR51430, 3 A class.
- 3.3 V rail: LMR51430, 3 A class.
- SIM800 rail: 4.0 V, LMR51430, 3 A class; design for 2 A radio bursts at the module.
- Keep GSM high-current traces short/wide and place bulk capacitance at the module connector.

## Regulator feedback candidates

Using the LMR51430 nominal VFB = 0.6 V:

- 5.0 V: Rbottom = 100 kΩ, Rtop = 732 kΩ -> ~4.99 V
- 4.0 V: Rbottom = 100 kΩ, Rtop = 567 kΩ -> ~4.00 V
- 3.3 V: Rbottom = 100 kΩ, Rtop = 450 kΩ -> ~3.30 V

These are starting values for the calculator/PCB review; use E96 resistors and verify the final feedback layout against TI's datasheet and the selected switching-frequency option.

## BOM policy

The BOM is split into:

- **FROZEN:** exact MPN is supported by authoritative source data.
- **PROCUREMENT HOLD:** the architecture is frozen but an exact module/connector/footprint must be selected from the physical supplier lot.
- **ASSEMBLY OPTION:** interchangeable alternatives that should not be mixed on a single PCB revision without schematic/footprint review.

## Safety review

- Aerator command safe state: ON.
- DO circulation pump safe state: OFF.
- MCU GPIO never drives a mains load directly.
- SIM800 is isolated from 3.3/5 V logic power by its own regulator rail.
- PV input receives fuse/TVS before charger stage.
- Battery pack requires a 2S protection/BMS solution before PCB release.
- High-impedance pH node stays physically separated from switching/GSM/relay routing.
