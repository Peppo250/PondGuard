# M4 — ESP32 Firmware Integration

## Goal

Move the PondGuard control logic from Python-only execution into C++ interfaces
that compile natively and can also target the ESP32-C3.

## Architecture

```text
                        EnvironmentalSample
                               |
                               v
                       PondGuard Controller
                               |
              +----------------+----------------+
              |                                 |
              v                                 v
        Crash score                        ActuatorCommand
                                                |
                                  +-------------+-------------+
                                  |                           |
                                  v                           v
                              Aerator                    DO pump
```

## M4 implementation

### Cross-platform controller

`firmware/src/control/controller.cpp`

The controller is independent of Arduino APIs. This allows:
- native compilation
- fast unit tests
- future Wokwi execution
- eventual physical ESP32 execution

### ESP32 platform layer

`firmware/src/platform/arduino_hardware.cpp`

This layer maps:
- analog inputs
- DS18B20
- relay outputs

to the common PondGuard interfaces.

### Safety

The Arduino actuator driver starts with the aerator ON.
Invalid sensor data also commands the aerator ON.

### Current limitation

Analog conversion in this first firmware milestone is deliberately a
simulation-oriented abstraction. Exact calibration of:
- galvanic DO + TIA
- SEN0567
- pH electrode + AD8603 + ADS1115
- battery divider

is deferred to the hardware integration milestone.

Do not treat the analog conversion formulas as final calibrated sensor drivers.

## Native build

```bash
python tools/build_native.py
```

Run the native smoke test binary after building.

## Native controller tests

```bash
python tools/run_native_tests.py
```

## ESP32 build

With PlatformIO installed:

```bash
pio run -e esp32-c3-devkitm-1
```

The ESP32 build is the transition point from M3's Python controller
experiments to embedded execution.

## Acceptance criteria

M4 is complete when:
1. controller logic compiles outside Arduino
2. native tests pass
3. ESP32 target compiles
4. sensor and actuator interfaces remain separated
5. fail-safe aerator behavior is preserved
6. no field-validation claims are made from firmware simulation
