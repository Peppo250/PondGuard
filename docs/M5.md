# M5 — Wokwi Hardware Simulation

## Objective

Run the M4 ESP32-C3 firmware against a visible virtual hardware harness.

## What is validated

- ESP32-C3 target structure
- GPIO-to-actuator mapping
- analog sensor input flow
- DS18B20 input flow
- relay activation
- buzzer output
- SD logging path
- serial telemetry
- fail-safe startup behavior
- controller execution on the simulated MCU

## What is not validated

Wokwi does not reproduce the project's physical:
- galvanic DO electrochemistry
- LM358 transimpedance behavior
- AD8603 high-impedance pH interface
- ADS1115 analog front end
- SEN0567 gas-sensor chemistry
- ePTFE diffusion chamber
- solar/charger/battery physics

Therefore the four potentiometers are sensor-boundary emulators.

## M5 acceptance criteria

1. `diagram.json` parses.
2. Wokwi harness contains ESP32-C3.
3. Firmware contains the canonical relay mapping.
4. Firmware starts the aerator in the safe state.
5. Sensor values appear in Serial Monitor.
6. Low DO commands the aerator ON.
7. Higher DO can release the aerator under hysteresis conditions.
8. SD log format is produced.
9. M1–M4 tests remain passing.

## Wokwi workflow

The repository, not Wokwi, remains the source of truth.

```text
config
  ↓
firmware
  ↓
wokwi/generated
  ↓
Wokwi
```

Changes to the hardware map should begin in `config/hardware.yaml`.
