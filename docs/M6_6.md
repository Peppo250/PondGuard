# M6.6 — Unified Complete KiCad Schematic

## Goal

Combine the validated PondGuard M6.1–M6.5 hardware decisions into one unified schematic reference covering:

- power / protection interfaces
- pH high-impedance front end
- dissolved-oxygen interface
- NH3 gas interface
- DS18B20 temperature probe
- ADS1115 analog acquisition
- ESP32-C3 MCU
- MicroSD SPI
- SIM800L UART and dedicated supply interface
- aerator and DO-circulation driver stages
- watchdog/reset and safety annotations

## Source of truth

`config/hardware.yaml` and `config/pinmap_m6_5.json` remain authoritative for MCU pin allocation.

## GPIO allocation

| Signal | GPIO |
|---|---:|
| AERATOR_DRIVER | 0 |
| DO_PUMP_DRIVER | 1 |
| SD_CS | 3 |
| DS18B20 | 4 |
| NH3_ADC | 5 |
| I2C_SDA | 6 |
| I2C_SCL | 7 |
| SD_SCK | 10 |
| SD_MOSI | 18 |
| SD_MISO | 19 |
| GSM_RX | 20 |
| GSM_TX | 21 |

GPIO2, GPIO8 and GPIO9 are deliberately unused because they are ESP32-C3 strapping pins. GPIO12–17 are reserved for the internal flash/PSRAM interface. GPIO18/19 are intentionally used for MicroSD SPI, which sacrifices the USB-JTAG function in this configuration.

## ADS1115 channels

- AIN0: buffered pH signal
- AIN1: DO interface output
- AIN2: 2S battery divider
- AIN3: buffered 1.65 V pH bias reference

The pH measurement remains differential AIN0-AIN3.

## GSM interface

The SIM800L interface is shown as a dedicated ~4.0 V rail with local bulk/ceramic bypass. The ESP32 TX path uses the M6.5 1 kΩ series + 10 kΩ pulldown arrangement. The exact SIM800L breakout UART input level must be validated on the purchased module before PCB release.

## Actuation

GPIO0 and GPIO1 are logic-level driver commands only. External transistor/SSR/relay stages perform the actual switching. The aerator path is the environmental fail-safe and is documented as ON; the DO circulation pump is measurement support and is documented as OFF.

## NH3 scientific boundary

The SEN0567 is retained as a qualitative gas-phase sensing element. The schematic does not encode a raw-voltage-to-dissolved-NH3 conversion. Any dissolved-NH3 model must follow chamber/membrane characterization and calibration.

## Status

This is a unified **pre-PCB engineering schematic** generated from the M6.5 validated architecture. It should not yet be treated as a manufacturing release because exact regulator parts, PCB footprints, connectors, isolation distances, creepage/clearance, fuse ratings, battery/BMS details, PV operating point, and the purchased SIM800L/SSR variants still require final procurement and electrical review.
