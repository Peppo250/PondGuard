# M6.5 — MCU + Peripherals + Relay + GSM Integration

## Goal

Unify the ESP32-C3 GPIO allocation, ADS1115 analog bus, MicroSD SPI bus,
SIM800L UART, DS18B20, NH3 ADC input, and two actuator outputs without
pin collisions.

## Final M6.5 GPIO map

| GPIO | Function |
|---:|---|
| 0 | Aerator driver output |
| 1 | DO circulation-pump driver output |
| 3 | MicroSD CS |
| 4 | DS18B20 1-Wire |
| 5 | SEN0567 NH3 analog ADC |
| 6 | I2C SDA |
| 7 | I2C SCL |
| 10 | MicroSD SCK |
| 18 | MicroSD MOSI |
| 19 | MicroSD MISO |
| 20 | SIM800L RX into ESP32 |
| 21 | ESP32 TX to SIM800L |

GPIO2, GPIO8 and GPIO9 are intentionally avoided because they are
ESP32-C3 strapping pins. GPIO12–17 are avoided because they are normally
associated with the SPI0/1 flash/PSRAM interface. Espressif documents GPIO18
and GPIO19 as the USB-JTAG pins; reusing them as normal GPIO disables that
USB-JTAG function, which is an explicit M6.5 trade-off.

## ADS1115 allocation

The 4-channel ADC removes the previous MCU-pin conflicts:

- AIN0: pH buffered signal
- AIN1: DO interface output
- AIN2: 2S battery divider
- AIN3: pH 1.65 V bias reference

pH remains differential AIN0-AIN3.

## SIM800L power and UART

SIM800 hardware documentation specifies a 3.4–4.4 V supply, 4.0 V
recommended, and up to 2 A current during transmit bursts. A dedicated
~4.0 V rail is therefore retained instead of using the 3.3 V or 5 V logic
rails. Place low-ESR bulk capacitance at the module.

M6.5 uses:
- ESP32 TX -> 1 kΩ series -> SIM800 RX node
- 10 kΩ pulldown from SIM800 RX node to ground
- SIM800 TX -> ESP32 RX direct for first prototype, subject to validation
of the exact SIM800L breakout's UART levels.

The SIM800L hardware guide also recommends local bypass capacitance and
careful low-impedance power routing.

## Relay / SSR actuation

GPIO0 and GPIO1 are logical outputs only. They must feed an external
transistor/driver stage and never directly switch mains.

The aerator path is fail-safe ON:
- MCU boot/reset default must not disable the external aerator safety path.
- Firmware explicitly drives the aerator command ON during startup.
- A watchdog timeout must leave the hardware stage in the documented safe
state.

The DO circulation pump is measurement-support only and defaults OFF.

## Watchdog

M6.5 adds a hardware watchdog requirement at the firmware architecture
level. The task must feed the watchdog during the normal loop; a blocked
task must trigger a reset. The external actuator interface must preserve
the documented safe state across reset.

## Current-budget model

The 3.3 V rail covers low-power logic and sensors; SIM800L receives a
separate ~4.0 V high-current rail. Do not sum the 2 A GSM transmit burst
into a low-current 3.3 V regulator specification.

## Acceptance criteria

1. No duplicate GPIO assignment.
2. No use of ESP32-C3 strapping pins in the final map.
3. ADS1115 owns DO, pH and battery high-resolution analog channels.
4. NH3 remains on GPIO5 with its M6.4 protection network.
5. MicroSD has a dedicated SPI bus map.
6. SIM800L has dedicated UART and ~4.0 V power architecture.
7. Actuator outputs are logical driver inputs, not mains outputs.
8. Aerator fail-safe behavior remains ON.
9. Watchdog requirement is represented in firmware.
10. Native test suite remains hardware-independent.
