# M7.1 — Complete Wokwi Hardware-Interface Simulation

## Objective

Replace the legacy M5 Wokwi harness with a connection-level simulation matching the M6.7 hardware map.

## M6.7 map implemented

| Function | ESP32-C3 / Peripheral |
|---|---|
| Aerator logical driver | GPIO0 |
| DO circulation pump | GPIO1 |
| MicroSD CS | GPIO3 |
| DS18B20 | GPIO4 |
| SEN0567 analog | GPIO5 |
| ADS1115 SDA | GPIO6 |
| ADS1115 SCL | GPIO7 |
| MicroSD SCK | GPIO10 |
| MicroSD MOSI | GPIO18 |
| MicroSD MISO | GPIO19 |
| SIM800L RX/TX | GPIO20/21 |
| ADS1115 AIN0 | pH signal |
| ADS1115 AIN1 | DO signal |
| ADS1115 AIN2 | battery divider node |
| ADS1115 AIN3 | pH bias |

## Simulation model

The four potentiometers are electrical stimulus sources at the conditioned interface nodes. The custom ADS1115 Wokwi chip performs I2C register transactions and produces signed 16-bit conversion codes from those analog node voltages. The firmware then converts the readings to DO, pH and battery values.

The GSM section is intentionally an interface-only model in M7.1: GPIO20/21 are exposed to the logic analyzer. No cellular network behavior is claimed.

## Safety

- Aerator starts ON.
- Invalid sensor sample forces aerator ON.
- DO circulation pump starts OFF.
- Relay modules represent logical driver outputs only; no mains load is connected.
