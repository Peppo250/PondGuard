# M6.4 — Free Ammonia NH3 Interface

## Status

M6.4 converts the SEN0567 concept into a safe electrical interface and
corrects the project's previous overstatement of quantitative sensor
capability.

## Vendor-verified sensor facts

DFRobot lists SEN0567 as:
- NH3 gas sensor
- 1–300 ppm detection range
- 3.3–5 V supply
- <20 mA current
- analog voltage output
- 4.7 kΩ load resistance
- −10 to 50 °C operating range
- 15–90%RH non-condensing

DFRobot explicitly states that the MEMS sensor is qualitative only and
suggests a factory-calibrated sensor for quantitative measurement.

## Electrical architecture

```text
SEN0567 A
   |
  1k
   |
   +--------> ESP32 ADC GPIO5
   |
 100nF
   |
  GND
```

plus rail clamps/protection.

The prototype sensor supply is 3.3 V so that the sensor output is designed
around the MCU voltage domain.

## Critical chemistry limitation

The SEN0567 measures NH3 in the gas phase.

PondGuard wants free ammonia in pond water.

There is therefore an intermediate transfer function:

```text
dissolved NH3
     ↓
membrane transfer
     ↓
headspace NH3
     ↓
SEN0567 voltage
```

That transfer function depends on chamber and environmental conditions.
It must be calibrated experimentally.

Therefore M6.4 does NOT implement a universal:

`SEN0567 ppm -> dissolved free NH3 mg/L`

equation.

## Warm-up state

The sensor requires a startup warm-up period according to DFRobot guidance.
Firmware should have:

```text
BOOT → WARMUP → BASELINE → MEASUREMENT
```

## Chamber

The proposed hydrophobic/ePTFE membrane chamber remains a research component.
It needs bench characterization for:
- response time
- leak rate
- membrane transfer
- condensation
- humidity
- temperature
- gas mixing
- cross-sensitivity

## Heater correction

The current official SEN0567 documentation exposes a three-pin interface
(A/VCC/GND) and specifies total sensor operating current below 20 mA.
M6.4 therefore does not invent an external 750 mW heater circuit.

If a purchased sensor variant contains a different heater architecture,
that exact hardware must be documented before adding a heater switch.

## Quantitative reference strategy

For research validation, compare the low-cost MEMS system against a
factory-calibrated NH3 reference sensor or a validated laboratory gas
concentration method.

That lets the paper report:
- qualitative event detection
- response/recovery time
- correlation after empirical calibration
- false-alarm behavior

without claiming unsupported absolute accuracy.

## Acceptance criteria

1. safe 3.3 V ADC interface
2. warm-up state
3. baseline capture
4. protected analog input
5. chamber characterization plan
6. explicit qualitative-sensor limitation
7. no universal dissolved-NH3 conversion
8. BOM and schematic notes
