# M6.2 — Dissolved Oxygen Analog Front-End

## Status

M6.2 resolves the DO electronics interface before fabrication.

## Critical finding

The selected DFRobot SEN0237-A is not a bare probe-only part. It includes a
galvanic probe and a signal-conditioner board with a 0–3 V analog output.

Therefore the custom TIA and the vendor conditioner are alternatives.

## Recommended first hardware prototype

```text
SEN0237-A
  ↓
DFRobot conditioner
  ↓
ADS1115
  ↓
ESP32-C3
```

This is the lower-risk route for first bring-up.

## Custom research path

```text
Bare galvanic probe
  ↓
LM358B TIA
  ↓
ADS1115
  ↓
ESP32-C3
```

Baseline TIA:
- Rf = 47 kΩ
- Cf = 100 nF
- assumed probe current = 1–3 µA

Expected TIA output:
- 47 mV at 1 µA
- 94 mV at 2 µA
- 141 mV at 3 µA

These are calculations, not measured sensor results.

## Calibration

The SEN0237-A documentation specifies calibration because saturated output
depends on the probe and temperature. The implementation should store
calibration coefficients and use the DS18B20 temperature reading for
temperature-aware conversion.
